[h1]HOI4 Fantasy World Map Maker[/h1]
[b]v1.0.1 Beta[/b]

A standalone desktop tool for creating complete HOI4 total-conversion mods from scratch without manually editing game files.

[b]Features:[/b]
[list]
[*] Draw land, sea, and lakes with circular brush, fill, and transform tools
[*] Generate provinces automatically with Poisson-disk sampling and Lloyd relaxation
[*] Control province density with a density map
[*] Generate heightmaps with coastal-distance fields, Perlin-noise mountains, and user-controlled refinement
[*] Assign terrain from height and noise data
[*] Generate rivers from heightmap flow accumulation
[*] Manage states, countries, strategic regions, and continents
[*] Edit railways, supply nodes, and strait adjacencies
[*] Export a complete mod in one operation
[*] Import existing HOI4 map data
[*] Undo and redo editing operations
[*] English-only interface and export localization
[/list]

[b]How to use:[/b]
After subscribing, find the tool folder in your Steam Workshop directory and run [i]hoi4_map_maker.exe[/i].
Typical path: [i]Steam\steamapps\workshop\content\394360\<id>\hoi4_map_maker.exe[/i]

[b]Supported map sizes:[/b] 2048x1024 / 3072x1536 / 4096x2048 / 5632x2048

[b]Requirements:[/b] Windows 10+, HOI4 1.17.x
